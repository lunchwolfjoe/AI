# How Stories Work

This is a sample story demonstrating the content system. Stories are written in Markdown and stored in the `content/stories/` directory.

## Adding a New Story

1. Create a new `.md` file in `content/stories/`
2. Add frontmatter at the top (see below)
3. Write your content in Markdown

## Frontmatter Fields

Each story should include this frontmatter at the top:

```yaml
---
title: "Your Story Title"
date: "YYYY-MM-DD"
excerpt: "A brief summary for listing pages"
author: "Author Name"
part: 1  # Optional: which part of the series
---
```

## Markdown Features

You can use all standard Markdown features:

### Text Formatting

- **Bold text** for emphasis
- *Italic text* for softer emphasis
- `Code snippets` for technical terms

### Blockquotes

> This is a blockquote. Use it for highlighting key statements or quotes from sources.

### Lists

Numbered lists work well for procedures:

1. First step
2. Second step
3. Third step

### Links

Link to [evidence](/evidence) or [external sources](https://example.com).
