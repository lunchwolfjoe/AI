# TEXANS FIRST* — Visual Narrative Plan

**Version 1 — September 1, 2026**

One visual system for the site, six-story series, evidence report, documentary and short-form publication.

## Visual Thesis

The investigation is complicated because the records live in separate systems. The visual language should make the separation itself visible: Texas records the contract, payment, economic-development announcement, lobbying registration and overseas investment as different objects. The audience should repeatedly see those objects join — and then see the worker-level field that is missing.

**The visual package should not depict ethnicity, nationality or immigration status as a proxy for wrongdoing.** People are shown because of documented institutional roles. Companies are shown because of contracts, lobbying, investment, association membership or operating infrastructure. Every line in a network graphic must correspond to a record.

---

## Design Grammar

| Element | Meaning | Rule |
|---------|---------|------|
| **Solid line** | Documented relationship | Contract, appointment, lobbying registration, board role, mission participation, MOU/land record or other preserved record. |
| **Dashed line** | Open transaction question | Use only when the graphic itself labels the missing proof; never render as an established relationship. |
| **Large numeral** | Verified/official quantitative anchor | Label announced/reported metrics as such. Never strip the qualifier from FDI/job figures. |
| **Document thumbnail** | Primary record | Show agency/source, date and highlighted passage. Avoid tiny unreadable screenshots. |
| **Gray/neutral node** | Contextual entity | Entity is relevant but not accused of misconduct. |
| **Question-mark field** | Missing public accounting | Use for worker residency, actual work geography, subcontractor or visa-category fields when the record does not disclose them. |
| **Timeline marker** | Documented dated event | Every marker links to evidence card/source. |

## Network-Diagram Rules

Network diagrams are the highest-risk visuals because proximity can imply conspiracy. Every edge must carry a verb and date: *appointed, represented, contracted with, traveled with, chaired, donated, recruited, allotted land to, subleased to.* Never use an unlabeled line.

- No nationality-based clusters
- No inferred family, caste, religion or diaspora-command relationships
- No line from HSS/RSS to Texas procurement, APNRTS or ITServe unless a primary record establishes institutional direction/control
- A person appearing in two institutions is an overlap, not proof that the institutions coordinated
- Use dashed edges only for explicitly labeled questions
- Clicking an edge on the site should open the exact evidence card supporting that edge
